# PCSI: Communicative Stance in University IP Policies

This repository holds the manuscript and replication materials for

> **Communication as Governance: Measuring Communicative Stance in University Intellectual Property Policies** (working paper, October 2026)

The paper builds the Policy Communication Stance Index (PCSI), a measure of supportive versus restrictive language in the intellectual-property policies of 150 U.S. research universities, 1944–2025.

This is the primary repository for the final paper. Earlier development work is archived at [krish533/Tech-transfer-1](https://github.com/krish533/Tech-transfer-1).

## Current manuscript (October 20, 2026)

- [Full LaTeX manuscript](manuscript/main.tex) includes the revised abstract, main text, Data and Code Availability statement, and all eight appendix sections. All appendix sections and appendix tables have cross-references from the main text.
- [Bibliography](manuscript/references.bib), [tables](manuscript/tables/), and [figures](manuscript/figures/) are stored alongside the manuscript. The `manuscript/` directory can be used as an Overleaf project.
- **Interpretation:** PCSI measures how IP policy language expresses obligations, authority, and support. A score below 0.50 is not a judgment that a university policy is bad, unfair, or ineffective. The manuscript does not estimate effects on faculty or TTO behavior.
- **Reproducibility:** The tables and figures can be rebuilt from the released scores. Classifier weights require the archived repository (instructions below); the original human-coded labels were not preserved, so the original training evaluation cannot be independently repeated.

## Compile the manuscript

The `manuscript/` folder is self-contained. Upload it to Overleaf (or link this repository through Overleaf's GitHub integration and set `manuscript/main.tex` as the main document), or compile locally:

```bash
cd manuscript
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Reproduce the tables and figures

Python 3.10 or later. From the repository root:

```bash
pip install -r replication/requirements.txt
python replication/pipeline/run_all.py --skip-scoring        # panels, analyses, figures (about 1 minute)
python replication/paper_outputs/code/audit_manuscript_numbers.py   # recomputes 39 reported numbers independently
python manuscript/build_tables.py                            # writes manuscript/tables and manuscript/figures
```

`--skip-scoring` starts from the released classifier scores (`replication/data/derived/sentence_scores_canonical.csv`). Running `run_all.py` without it re-scores all 87,160 archive sentences with the classifier, which needs the model weights (see `replication/model/README.md`) and several hours on a CPU. `replication/paper_outputs/code/verify_inference_reproducibility.py --n 2000` re-scores a random sample instead and compares it with the released scores.

## What has been verified

- The pipeline above ran from this repository's files and regenerated every manuscript table; the regenerated tables match the paper.
- `audit_manuscript_numbers.py` recomputes 39 reported statistics with code written separately from the analysis scripts; all match.
- Re-scoring a random 2,000-sentence sample with the saved classifier reproduced the released probabilities to within 4×10⁻⁶, with identical labels (run in the archived repository, where the weights are stored).
- The original classifier training run cannot be reproduced: the 2,732 adjudicated training and validation sentences and the coders' individual labels were not preserved. The reported accuracy (90.1%) and macro-F1 (0.894) are stored in `replication/model/srn_cls_model/metrics.json`.
